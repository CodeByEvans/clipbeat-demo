ClipBeat Demo es una aplicación de ejemplo desarrollada con **Ionic 7 y Angular 17** que simula un perfil de usuario moderno, con funcionalidades como:

- Contenedor principal de información del perfil.
- Edición de perfil mediante botón `create`.
- Visualización de redes sociales integradas.
- Feed de publicaciones estilo TikTok con likes, comentarios y compartir.
- Sidebar de ajustes accesible mediante menú hamburger.
- Botón para compartir el perfil.
- Tour interactivo guiado usando **Intro.js** para presentar cada sección de la app.

El proyecto está pensado para mostrar **buenas prácticas de Ionic**, integración de **localStorage** para datos del usuario, y despliegue simple a plataformas como **GitHub Pages o Vercel**.
